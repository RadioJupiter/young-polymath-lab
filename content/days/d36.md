## Core lesson: a letter for an unknown {#core}

<p class="meta">40 minutes · Method: a missing part on a bar, then a letter, then a short equation</p>

Sometimes a number is missing, and we want a way to name it while we work. In a bar model, we can leave that part blank, or write a letter in it.

A **letter**, such as *n*, stands for **one unknown number** in a problem. It is not a decoration, and it is not a new kind of number. It is a name for the missing part.

**From the bar to an equation.** The bar above shows a whole of 15. One part is 6. The other part is unknown, so we write *n*. The picture says:

**n + 6 = 15**

To find *n*, think: the missing part is the whole take away the known part. *n* = 15 − 6 = **9**. Check: 9 + 6 = 15.

We can use other letters (*x*, *a*), but in one problem the same letter means the same number each time it appears.


</div>

<div class="remember" data-listen="en-US">

<p class="kicker">Remember</p>

A letter stands for one unknown number in a problem. A bar shows the missing part. n + 6 = 15 means the missing part plus 6 makes 15, so n = 9. Check by putting the number back.

</div>

<div class="watch" data-listen="en-US">

<h3>Watch me</h3>

<p>A bar has a whole of 20. One part is 8. The other part is *n*. Write the equation and find *n*.</p>
<ol class="steps">
<li>The picture is n + 8 = 20.</li>
<li>The missing part is 20 − 8 = 12, so n = 12.</li>
<li>Check: 12 + 8 = 20.</li>
</ol>

</div>

<div class="together" data-listen="en-US">

<h3>Together</h3>

<p>A bar has a whole of *n*. One part is 9 and the other part is 11. Write the equation and find *n*.</p>
<details>
<summary>Hint 1: The whole</summary>

The whole is the two parts together, so n = 9 + 11.

</details>
<details>
<summary>Hint 2: The equation</summary>

9 + 11 = n, or n = 20.

</details>

</div>

<div class="check">

<h3>Check</h3>

<p>Use a bar, then a letter, then a check.</p>

1. Write an equation for a whole of 18, with parts n and 5, and find n.
2. Why is n not “just a label,” like a name tag that does no work?

</div>

### Practice

1. A whole of 24 is split into n and 16. Find n, and check.
2. In one problem, n appears twice: n + n + 4 = 16. What is n?
3. A friend writes n + 7 = 10 and then says n can be 2 in one line and 5 in the next line of the same problem. What would you say?
4. Draw a bar for n − 3 = 8, then find n.

### Answer key

**Check.**
1. n + 5 = 18, so n = 13. Check: 13 + 5 = 18.
2. A letter stands for a number we can find and check. It is a name for the missing part, not a sticker.

1. n = 8, because 24 − 16 = 8. Check: 8 + 16 = 24.
2. n + n is 2n, and 2n + 4 = 16, so 2n = 12 and n = 6. Check: 6 + 6 + 4 = 16. Both n’s are 6.
3. In one problem the same letter means the same number each time. You can use n again in a new problem, but not as two different numbers in the same one.
4. The bar’s whole is n; a part of 3 is marked off; 8 is left. So n = 8 + 3 = 11. Check: 11 − 3 = 8.

### Practice

1. n + n = 18. Find n.
2. An invented shelf holds 40 books. 15 are on the first pile and n are on the second. The two piles together are the whole shelf. Find n.
3. Why can we use the letter n again in this new shelf problem, even though n was 15 in an earlier problem?

### Answer key

**Check.**
1. n = 14 + 9 + 7 = 30.
2. The two sides are already the same for any number n, because adding 3 on the left or on the right is the same change. It does not, by itself, tell us a single value of n.

1. 2n = 18, so n = 9. Check: 9 + 9 = 18.
2. 15 + n = 40, so n = 25. Invented shelf. Check: 15 + 25 = 40.
3. A new problem can reuse the letter. The letter only has to keep one meaning inside one problem.

## Math circle: the same letter, the same number {#circle}

<p class="meta">20 minutes · a short argument, then a check of the reason</p>

<div class="learn" data-listen="en-US">

<h3>Learn</h3>

Why must the same letter mean the same number each time it appears in one problem?

</div>

<div class="remember" data-listen="en-US">

<p class="kicker">Remember</p>

In one problem, a letter is a name for one unknown number. If we let it change mid-problem, the picture and the check fall apart.

</div>

<div class="watch" data-listen="en-US">

<h3>Watch me</h3>

<p>A friend writes n + n = 10, then says “the first n is 2 and the second n is 8.” What would you say?</p>
<ol class="steps">
<li>n + n means two of the same number.</li>
<li>2 + 8 = 10 is a true sum, but it is not n + n unless n is both 2 and 8 at once, which a single letter cannot be in this problem.</li>
<li>n + n = 10 means 2n = 10, so n = 5. Check: 5 + 5 = 10.</li>
</ol>

</div>

<div class="together" data-listen="en-US">

<h3>Together</h3>

<p>Why is it still all right to use n tomorrow for a different unknown?</p>
<details>
<summary>Hint 1: A new problem</summary>

A letter is a name we give for one sitting of a problem.

</details>
<details>
<summary>Hint 2: The habit</summary>

A new problem can reuse the name. Inside one problem, the name stays still.

</details>

</div>

<div class="check">

<h3>Check</h3>

<p>These check the reason.</p>

1. In n + 4 = 12, can n be 8 on the first line and 9 on the check? Why or why not?
2. Give one reason we write a letter at all, instead of leaving a blank box forever.

</div>

### Practice

1. Write n + n + n = 15 as a short multiplication, and find n.
2. A friend says a letter is “not a real number.” What would you say?
3. This argument is not a score or a badge.

### Answer key

**Check.**
1. No. The check has to use the same n you found. 8 + 4 = 12, so n = 8 stays 8.
2. A letter lets us write the missing part in an equation and talk about it, then find its value and check.

1. 3n = 15, so n = 5. Check: 5 + 5 + 5 = 15.
2. The letter is a name for a number. Once we find it, we have an ordinary number, and we can check it.
3. A note that the circle is a reason to talk through, not a reward.
