Remember

d = 2r. C = πd = 2πr. π is not exactly 3.14 or 22/7; those are labeled approximations. NASA diameters may be given a circumference only with π and rounding named. A crater circumference is a circle model, not a surveyed walk.

1. A circle has diameter 8 m (invented dish, labeled invented). Using π ≈ 3.14, find C.

2. Using π ≈ 3.14 and Mars’s diameter about 6,792 km, what circumference does this course write, and what must be labeled?

3. Radius 7 cm, using π ≈ 22/7: find d, then C.

4. Earth, about 12,756 km across: using π ≈ 3.14, compute C, then give a nearest-thousand rounding, with both labels.

5. Tycho is about 85 km across (NASA). If we model the rim as a circle and use π ≈ 3.14, what C do we get, and what must the sentence still say?

6. Why did Level 7 refuse a circumference of Mars, and why may we compute one now?
