Core lesson: a letter for an unknown

Unit 8 · Day 36 · A letter for an unknown · one-lesson review

Review sheet — use this after the lesson. These questions practice only what this lesson taught. Answers are on the day's answer-key page, not here.

NameDate

Remember

A letter stands for one unknown number in a problem. A bar shows the missing part. n + 6 = 15 means the missing part plus 6 makes 15, so n = 9. Check by putting the number back.

1. Write an equation for a whole of 18, with parts n and 5, and find n.

2. Why is n not “just a label,” like a name tag that does no work?

3. A whole of 24 is split into n and 16. Find n, and check.

4. In one problem, n appears twice: n + n + 4 = 16. What is n?

5. A friend writes n + 7 = 10 and then says n can be 2 in one line and 5 in the next line of the same problem. What would you say?

6. Draw a bar for n − 3 = 8, then find n.

Work in writing. Then mark from the answer key and rework every miss the next day.
