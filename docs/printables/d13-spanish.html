Remember

la luna llena, la luna nueva, el cuarto creciente, el cuarto menguante. Veo la luna llena. The name cuarto, like ‘quarter’, is about the cycle, not a quarter-lit disk.

1. Write: I see the new Moon.

2. Which phrase is first quarter? Which is full?

3. Translate: On Friday I see the third quarter. Today I see the full Moon. (Hoy from Day 11.)

4. Write two original sentences, each with a different phase word.

5. In one English sentence, say what cuarto is tracking, so you do not shade only a quarter of a disk.
