Unit 8 · Day 36 · A letter for an unknown · one-lesson review

Remember

In one problem, a letter is a name for one unknown number. If we let it change mid-problem, the picture and the check fall apart.

1. In n + 4 = 12, can n be 8 on the first line and 9 on the check? Why or why not?

2. Give one reason we write a letter at all, instead of leaving a blank box forever.

3. Write n + n + n = 15 as a short multiplication, and find n.

4. A friend says a letter is “not a real number.” What would you say?

5. This argument is not a score or a badge.
