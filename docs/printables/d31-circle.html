Math circle: why both sides of a ratio change together

Unit 7 · Day 31 · Ratio as a comparison · one-lesson review

Remember

Equivalent ratios come from scaling both parts together. Adding the same number to both sides does not keep the ratio. 2 : 3 is not 3 : 2.

1. Name one way to write a ratio equivalent to 1 : 4.

2. Why is 5 : 2 not the same comparison as 2 : 5?

3. Give one reason 6 : 9 = 2 : 3.

4. If we only doubled the first number in 2 : 3, we would write 4 : 3. Why is that a different comparison?

5. Earth : Moon as 12,756 : 3,475 is a little less than 4 : 1. Why is forcing 4 : 1 not the same as simplifying?

6. What would go wrong if we treated a ratio as “just two numbers to add”?
