Remember

Compare in the same place. 0.4 = 0.40 as an amount. Invented readings stay labeled.

1. Order 1.05, 0.95, and 1.5 from least to greatest.

2. Which is greater, 0.99 or 1? By how many hundredths?

3. Find a decimal in hundredths that sits between 0.4 and 0.5.

4. Is 0.200 the same amount as 0.2? (Thousandths were named yesterday; 0.200 is 2 tenths and 0 hundredths and 0 thousandths.)

5. Why is “whichever has more digits is greater” false for 0.8 and 0.75?

6. An invented tank mark is 0.08 L from empty; another invented mark is 0.8 L from empty. Which is closer to 1 L? Label both invented.
