Math circle: same amount, different claimed precision

Unit 6 · Day 27 · Comparing decimals, and 0.4 = 0.40 · one-lesson review

Review sheet — use this after the lesson. These questions practice only what this lesson taught. Answers are on the day's answer-key page, not here.

NameDate

Remember

Equal amounts stay equal. A written trailing zero can still mark a finer reading when the number is a measurement. We do not invent precision that was not measured.

1. Are 0.70 and 0.7 the same amount?

2. Give one reason a written measurement 0.70 m might still be worth writing with the zero.

3. If a scale only has tenths, can it honestly write 0.35? Say why.

4. Does writing 3.14 for π claim that π is exactly 3.14, or is 3.14 still a labeled approximation?

5. A friend wants to write Mars as 6,792.00 km “to be more precise.” What do we say?

6. On the tenths number line, do 0.4 and 0.40 mark two different points?
