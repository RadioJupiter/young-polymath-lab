Remember

An odd number of odd addends cannot make an even total. The number of people with an odd number of handshakes must itself be even.

1. What is odd + odd + odd: odd or even?

2. Why must a count of 'hands used' in a room of handshakes be even?

3. Can you find four odd numbers that add up to 25? Try, and then explain why you can or cannot.

4. Five astronauts meet. Can each one shake hands with exactly three of the others? (Hint: count how many "hands used" there would be in total, and remember that every handshake uses exactly two hands.)
