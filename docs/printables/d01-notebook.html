Notebook · The Earth–Moon model

1. Draw first. Draw the Earth and Moon objects and the gap between them. You may compress the gap on the page, but write the real model distance.

2. Label from the word bank. Point, say the word, then write it on the drawing.

Word bank — Earth · Moon · kilometre (km) · centimetre (cm) · metre (m) · model · scale · distance · diameter

3. Write. Say each sentence aloud, then write it on the lines.

The Earth in the model is about ________.

The Moon in the model is about ________.

The gap between them is about ________.

What surprised me was ________.

4. Numbers and questions. Write the calculation for each model size (Earth, Moon, distance). Then write one question about the Moon.

For the guide: Draw first. Label from the word bank. The student says each sentence before writing. If handwriting is a struggle, write the student's own words in light pencil to trace or copy.
