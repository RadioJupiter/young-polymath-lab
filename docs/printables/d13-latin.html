Remember

Ubi est…? / Ubi sunt…? Answer with est / sunt and a place phrase: in caelō, in hortō.

1. Write: Where is the boy? The boy is in the garden.

2. Correct: Ubi sunt lūna?

3. Translate: Where is the night? (A thoughtful answer can be Nox est, or you may write Ubi est nox? and leave a place if you have one; Nox est is enough if no place is taught.) Better: Ubi est puella? Puella est in hortō. Write that pair.

4. Write two original question-and-answer pairs, one singular and one plural.

5. Correct: Ubi est stellae?

Work in writing. Then mark from the answer key and rework every miss the next day.
