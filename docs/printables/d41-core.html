Remember

A tally uses one mark for each thing counted, grouped in fives. A table organizes the same counts under clear headings. An invented classroom watch stays labeled invented; it is not an official meteor rate.

1. Which invented watch has the most meteors, and how many is that?

2. Write a tally for an invented count of 13, and say the number in groups of five and leftovers.

3. A new labeled invented watch has counts 5, 9, and 6. Make a two-column table and find the total.

4. Why must this lesson not call 30 an official rate for a named meteor shower?
