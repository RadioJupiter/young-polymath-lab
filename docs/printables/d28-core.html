Remember

Line up the decimal point so the same places sit together. Writing a helpful zero (0.4 as 0.40) does not change the amount. Regroup tenths and ones the same way as in whole-number subtraction. Invented lengths stay labeled.

2. 2.5 − 0.8.

3. 1.36 + 0.4 (again, as a written sum with places lined up).
