Latin · altus, and three dimensions named (not SI)

Remember

altus / alta: high or tall. cista: a box. Adjectives match. No SI units in the Latin. Italian-voice Hear, labeled as an approximation.

1. Write: “The box is long and wide.”

2. Correct: *cista altus est.

3. Write a three-adjective description of a box (long, wide, not tall — or another honest combination).

4. Read the sentences aloud twice.

5. Draw a tall wall and a small box, labeled in Latin.

6. Write one new sentence with parva or parvus.

Work in writing. Then mark from the answer key and rework every miss the next day.
