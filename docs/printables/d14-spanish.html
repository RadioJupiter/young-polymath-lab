Remember

Quiero + infinitive: Quiero ver la luna. Puedo + infinitive: Puedo ver la luna llena. No puedo ver la luna nueva.

1. Write: I want to see the Moon.

2. Write: I can see the first quarter. (el cuarto creciente)

3. Translate: I want to see the sky. I cannot see the stars. (las estrellas — new, taught here: las estrellas, ‘the stars’.)

4. Correct: Quiero veo la luna.

5. Write two original sentences, one with quiero ver and one with puedo ver or no puedo ver.
