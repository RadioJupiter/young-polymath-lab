Core lesson: adding and subtracting like fractions

Unit 3 · Day 13 · Adding the same-size parts · one-lesson review

Review sheet — use this after the lesson. These questions practice only what this lesson taught. Answers are on the day's answer-key page, not here.

Remember

Like fractions (same denominator): add or subtract the numerators; keep the denominator. Then rename: 2/6 = 1/3, 3/6 = 1/2. Do not add denominators. A 12-day month is a classroom model, not the real 29½-day synodic month.

1. 3/8 + 1/8 = ? Give a simpler name if there is one.

2. On a 12-day model month, 5/12 + 3/12 = ? Is that half the model month?

3. 2/5 + 1/5 and 4/5 − 1/5.

4. 1/6 + 1/6. Name the sum in sixths and in thirds.

5. A 12-day model month: 4/12 + 2/12, then a simpler name. Then write one sentence that this is a model, not 29½ days.

6. Which is longer on the same bar: 5/8 − 1/8, or 3/8 + 1/8? Or are they equal?

Work in writing. Then mark from the answer key and rework every miss the next day.
