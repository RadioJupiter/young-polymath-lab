Remember

To add unlike fractions, first rename them so the denominators match (a common denominator), then add as like fractions. 1/2 = 3/6.

1. 1/3 + 1/6 = ?

2. 2/3 − 1/6 = ?

3. 1/2 + 1/4 (use fourths).

4. 3/4 − 1/2.

5. 1/3 + 1/3 + 1/6.

6. A 6-part bar: mark 1/2 and 1/6 and say what is left of the whole.
