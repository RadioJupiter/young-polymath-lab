Unit 6 · Day 28 · Adding and subtracting decimals

Today's big question: How do we add and subtract decimals by place value, and why do we line up the decimal point?

For the guide: Line up the point so ones sit under ones and tenths under tenths. A helpful zero (0.4 as 0.40) does not change the amount. Regroup as in whole-number subtraction. Do not add “the tails” as if they were the same place. Invented lengths stay labeled.

Mental math warm-up: a tenth plus a tenth, and times ten

10 minutes · say the answer, then explain how you got it

Learn

We can add tenths as tenths: 0.4 + 0.3 = 0.7, because 4 tenths + 3 tenths = 7 tenths. Multiplying by 10 moves each digit one place to the left: 0.25 × 10 = 2.5. That is the same place-value shift you used with 3.14 × 10 = 31.4.

Remember

Add tenths to tenths and hundredths to hundredths. × 10 moves every digit one place to the left. 10 tenths make 1 one.

Watch me

What is 0.8 + 0.5?

  1. 8 tenths + 5 tenths = 13 tenths.
  2. 13 tenths is 1 one and 3 tenths.
  3. So 0.8 + 0.5 = 1.3.

Together

What is 0.07 × 10?

Hint 1: The shift

Each digit moves one place to the left.

Hint 2: The result

7 hundredths becomes 7 tenths: 0.7.

Check

These use only today’s mental facts.

  1. 0.6 + 0.6.
  2. 0.04 × 10.

Practice

  1. 1.2 − 0.5 (think of 12 tenths minus 5 tenths).
  2. 3.14 × 10, and say what the 4 stands for in the answer.

Core lesson: adding and subtracting decimals

35–40 minutes · Method: concrete (tenths strips or hundredths grids joined or taken away), pictorial (the place-value chart), then the lined-up written sum

Learn

Add and subtract by place. Decimals add and subtract like whole numbers once the same places sit in the same columns. The decimal point is the sign we use to keep those columns lined up: ones under ones, tenths under tenths, hundredths under hundredths.

A worked sum. 1.36 + 0.4. Write 0.4 as 0.40 if it helps, so the hundredths have a partner: 1.36 + 0.40. Ones: 1 + 0 = 1. Tenths: 3 + 4 = 7. Hundredths: 6 + 0 = 6. The sum is 1.76. The chart shows the same work.

A worked difference. 2.05 − 0.7. Write 0.7 as 0.70: 2.05 − 0.70. Hundredths: 5 − 0 = 5. Tenths: we need 0 − 7, so we regroup 1 one as 10 tenths: 10 + 0 = 10 tenths, and the ones become 1; then 10 − 7 = 3 tenths. Ones: 1 − 0 = 1. The difference is 1.35.

What we do not do. We do not add “the numbers after the point” as if they were a separate whole number with its own private rule (0.4 + 0.25 is not “4 + 25 = 29, then put a point somewhere”). We also do not “count decimal places” as a multiplication trick; this lesson is addition and subtraction only.

Classroom lengths stay labeled invented. If two invented rods are 1.25 m and 0.8 m, the total 2.05 m is still invented. A NASA diameter stays the whole-kilometer figure we already used; we will not invent a decimal add-on to it.

Remember

Line up the decimal point so the same places sit together. Writing a helpful zero (0.4 as 0.40) does not change the amount. Regroup tenths and ones the same way as in whole-number subtraction. Invented lengths stay labeled.

Watch me

Add 1.36 + 0.4, lining up the places.

  1. Write 0.4 as 0.40 if it helps.
  2. 1 + 0 = 1 one; 3 tenths + 4 tenths = 7 tenths; 6 hundredths + 0 hundredths = 6 hundredths.
  3. The sum is 1.76.

Together

Find 2.05 − 0.7.

Hint 1: Helpful zero

Write 0.7 as 0.70, so you have 2.05 − 0.70.

Hint 2: Regroup

Regroup 1 one as 10 tenths, then 10 tenths − 7 tenths = 3 tenths, with 5 hundredths still there: 1.35.

Check

These use only lined-up addition and subtraction.

  1. 0.6 + 0.25.
  2. 2.5 − 0.8.

Practice

  1. 1.36 + 0.4 (again, as a written sum with places lined up).
  2. 3.14 − 0.04, using 3.14 only as a decimal to practice on, still labeled as an approximation of π, not as a changed value of π.
  3. An invented rod is 1.25 m and a second invented rod is 0.8 m. What is the total length? Label it invented.
  4. Why is 0.4 + 0.25 not 0.29?
  5. 5.6 + 0.45.

Challenge problems: regrouping across a one, and a length that is not a planet

20 minutes · after the core, or later if the core took the full sitting

Learn

These items need careful regrouping, and they keep invented lengths labeled. We still do not add a made-up decimal to a NASA diameter.

Remember

Line up the point. Regroup when a place is too small to subtract. Invented lengths stay labeled.

Watch me

Find 1.02 − 0.75.

  1. Line up: 1.02 − 0.75.
  2. Hundredths: 2 is less than 5, so regroup 1 tenth (1.02 is 10 tenths and 2 hundredths, after taking the 1 tenth from 0 tenths by regrouping the 1 one). Work: 1.02 = 102 hundredths; 0.75 = 75 hundredths; 102 − 75 = 27 hundredths.
  3. The difference is 0.27.

Together

Three invented pieces are 0.4 m, 0.35 m, and 0.9 m. What is the total, and what must the sentence say?

Hint 1: Same places

0.40 + 0.35 + 0.90.

Hint 2: The sum

0.40 + 0.35 = 0.75, plus 0.90 = 1.65 m, and all three pieces are invented.

Check

These stay with addition, subtraction, and labels.

  1. 10.0 − 0.25.
  2. 0.99 + 0.01.

Practice

  1. 1.2 − 0.85.
  2. An invented tank holds 2.5 L. 0.75 L is poured out (invented amount). How much is left? Label both invented.
  3. Why do we line up the decimal point, rather than lining up the last digits?
  4. 0.08 + 0.93.
  5. This course used Earth’s equatorial diameter as about 12,756 km (NASA). Why is “12,756 km + 0.45 km” not an official new NASA size from this lesson?

Math circle: why we line up the point

20 minutes · a short reason, then a check

Learn

The decimal point is not a decoration and not a plus sign. It marks the ones place, so that tenths sit under tenths when we add or subtract. Lining up the last written digit would treat 0.4 and 0.25 as if the 4 and the 5 were the same place, which they are not.

Remember

Line up the point because we are lining up place value. A helpful zero does not change the amount. The last digit is not always the same place.

Watch me

Show why 0.4 + 0.25 would go wrong if we lined up the last digits, and show the correct lining-up.

  1. Lining up last digits would put 4 under 5: as if we were adding 4 hundredths to 25 hundredths, which gives the false 0.29.
  2. The 4 in 0.4 is 4 tenths, which is 40 hundredths.
  3. Lining up the points puts 0.40 over 0.25, and 40 hundredths + 25 hundredths = 65 hundredths = 0.65.

Together

Why is writing 0.4 as 0.40, before adding 0.25, honest?

Hint 1: Amount

0.4 and 0.40 are the same amount.

Hint 2: The job

The written zero fills the hundredths column so the places stay visible. It does not invent a new measurement.

Check

These check the lining-up reason.

  1. In 0.4 + 0.25, which digits are the tenths?
  2. What goes wrong if we “add 4 and 25 and put a point in front”?

Practice

  1. Give one reason a helpful zero is not the same thing as inventing a more precise NASA size.
  2. Compute 0.5 + 0.5 two ways: as tenths, and as hundredths (0.50 + 0.50).
  3. Does lining up the point change 1.36 or 0.4, or only their written places in the sum?
  4. Why was 3.14 × 10 not today’s kind of problem, and what place-value idea did it still use?
  5. Finish: We line up the point because ____, but the last digits may not be the same place, so we will not line up the last digits instead.

Spanish · pone, quita, and junto

15 minutes · Instruction in English; Hear for Spanish words · present tense only

Learn

Word How to say it Meaning
pone POH-neh he/she/it puts (present)
quita KEE-tah he/she/it takes away (present)
junto HOON-toh together
separado seh-pah-RAH-doh apart, separate
la caja lah KAH-hah the box

Today’s words name putting something down, taking it away, and whether things are together or apart. Instruction stays in English. Adding and subtracting decimals stays in the English mathematics; the Spanish is a picture of hands and a box.

Original sentences: Pone la caja. Quita la caja. Está junto. Está separado.

For the guide: put a box down and take it away as you say pone and quita. Present tense only. No decimal sums in the Spanish.

Remember

pone; quita; junto; separado; la caja. Instruction in English. Hear for Spanish words. No decimal arithmetic in the Spanish.

Watch me

Say: “He/she puts the box.”

  1. Pone la caja.
  2. Pone is the putting. La caja is the box.
  3. This is a present-tense pattern.

Together

How do you say “He/she takes the box away”?

Hint 1: The verb

quita

Hint 2: The sentence

Quita la caja.

Check

These use only today’s phrases.

  1. Write: “It is together.” (using está junto)
  2. Write: “It is apart.”

Exercises

  1. Correct: *Pone el caja, if someone used the wrong article.
  2. Hear pone, quita, and junto, then use each.
  3. Why is quita not a Spanish lesson in subtracting 0.7 from 2.05?
  4. A pointing retell: puts the box, takes the box, together, apart.
  5. Copy one model sentence into the notebook.

Latin · tabula et rēgula adsunt

15 minutes · Method: picture-based Latin; original sentences. Instruction in English.

Learn

Word How to say it Meaning
tabula TAH-boo-lah a tablet, a writing-board (nominative, feminine)
rēgula RAY-goo-lah a ruler, a straight-edge (nominative, feminine)
Tabula et rēgula adsunt TAH-boo-lah et RAY-goo-lah AHD-sunt The tablet and the ruler are here
adsunt AHD-sunt they are here / they are present

The Hear-word button uses an Italian voice as an approximation of Latin, not the speech of ancient Rome.

Original sentences, not from a textbook: Tabula adest. Rēgula adest. Tabula et rēgula adsunt. Tabula nōn adest.

adest is “is here” for one; adsunt is “are here” for more than one. et joins the two nouns. Decimal sums stay in the English mathematics. No degree numbers and no SI units in the Latin.

For the guide: the student reads as much as possible. Point to a tablet or notebook and a ruler. Italian-voice Hear, labeled as an approximation.

Remember

tabula; rēgula; adest; adsunt; Tabula et rēgula adsunt. No decimals in the Latin. Italian-voice Hear, labeled as an approximation.

Watch me

Read: Tabula et rēgula adsunt. Why adsunt, not *adest?

  1. There are two things: the tablet and the ruler.
  2. adsunt is the form for more than one.
  3. adest would be right for one thing only: Tabula adest or Rēgula adest.

Together

Say: “The ruler is here.”

Hint 1: The noun

rēgula.

Hint 2: The sentence

Rēgula adest.

Check

These use only today’s patterns.

  1. Write: “The tablet is here.”
  2. Write: “The tablet is not here.”

Exercises

  1. Correct: *Tabula et rēgula adest.
  2. Read the four model sentences aloud.
  3. Draw a tablet and a ruler, labeled in Latin, with adsunt.
  4. Why are 1.36 and 0.40 left in the English mathematics?
  5. Copy one model sentence.

Notebook: a lined-up sum, a difference, and a because-sentence

60 minutes · draw first, then label, then write · How the notebook works · Review sheet

Learn

Write 1.36 + 0.40 in a place-value chart (sum 1.76), and write 2.05 − 0.70 (difference 1.35). Then complete because / but / so stems: we line up the decimal point because ones must sit under ones and tenths under tenths, but the last written digits may not be the same place, so we will not line up the last digits, and 0.4 + 0.25 will not be written as 0.29.

Remember

Draw and label first. Complete stems. A helpful zero does not change the amount. No points or badges — the page is the work.

Watch me

A model sentence: 1.36 + 0.4 is 1.76 because the places were lined up, but lining up the last digits would treat 4 tenths as 4 hundredths, so I will line up the point.

  1. 0.4 is 0.40 as an amount.
  2. The but names the false lining-up.
  3. The so chooses the point as a place marker.

Together

Finish: 0.4 + 0.25 is 0.65, because ________, but it is not 0.29, so ________.

Hint 1: The places

…40 hundredths plus 25 hundredths is 65 hundredths…

Hint 2: The so

…I will not add the written tails as if they were the same place.

Check

The page should show the written sums, the charts, and complete stems.

  1. Write the lined-up sum 1.36 + 0.40 = 1.76 and the difference 2.05 − 0.70 = 1.35.
  2. Write a three-stem explanation (because / but / so) of why we line up the point.

Practice

  1. Add an invented-rod total: 1.25 m + 0.8 m = 2.05 m, labeled invented.
  2. Tick the word-bank words you used: place, point, tenth, hundredth, regroup, invented, line up.
  3. The page is a record of today’s skill, not a badge.
  4. A note that a helpful zero (0.40) does not invent a NASA hundredth of a kilometer.
  5. File the page. It is not a reward.
