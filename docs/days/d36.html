Mental math warm-up: a missing number

10 minutes · say the answer, then explain how you got it

Learn

A number is missing in a number bond or a short fact. Find the missing number, then say how you knew.

Remember

A missing number is the part that makes the whole, or the other addend in a fact you already know.

Watch me

□ + 7 = 15. What is the missing number?

  1. The whole is 15. One part is 7.
  2. The missing part is 15 − 7 = 8.

Together

12 − □ = 5. What is the missing number?

Hint 1: The start

You start with 12 and take some away, and 5 is left.

Hint 2: The undo

The missing number is 12 − 5 = 7.

Check

These are missing-number facts.

  1. □ + 9 = 20.
  2. 3 × □ = 18.

Practice

  1. 16 − □ = 9.
  2. □ ÷ 4 = 6.

Core lesson: a letter for an unknown

40 minutes · Method: a missing part on a bar, then a letter, then a short equation

Learn

Sometimes a number is missing, and we want a way to name it while we work. In a bar model, we can leave that part blank, or write a letter in it.

A letter, such as n, stands for one unknown number in a problem. It is not a decoration, and it is not a new kind of number. It is a name for the missing part.

From the bar to an equation. The bar above shows a whole of 15. One part is 6. The other part is unknown, so we write n. The picture says:

n + 6 = 15

To find n, think: the missing part is the whole take away the known part. n = 15 − 6 = 9. Check: 9 + 6 = 15.

We can use other letters (x, a), but in one problem the same letter means the same number each time it appears.

Remember

A letter stands for one unknown number in a problem. A bar shows the missing part. n + 6 = 15 means the missing part plus 6 makes 15, so n = 9. Check by putting the number back.

Watch me

A bar has a whole of 20. One part is 8. The other part is n. Write the equation and find n.

  1. The picture is n + 8 = 20.
  2. The missing part is 20 − 8 = 12, so n = 12.
  3. Check: 12 + 8 = 20.

Together

A bar has a whole of n. One part is 9 and the other part is 11. Write the equation and find n.

Hint 1: The whole

The whole is the two parts together, so n = 9 + 11.

Hint 2: The equation

9 + 11 = n, or n = 20.

Check

Use a bar, then a letter, then a check.

  1. Write an equation for a whole of 18, with parts n and 5, and find n.
  2. Why is n not “just a label,” like a name tag that does no work?

Practice

  1. A whole of 24 is split into n and 16. Find n, and check.
  2. In one problem, n appears twice: n + n + 4 = 16. What is n?
  3. A friend writes n + 7 = 10 and then says n can be 2 in one line and 5 in the next line of the same problem. What would you say?
  4. Draw a bar for n − 3 = 8, then find n.

Challenge problems: two letters, or a hidden whole

25 minutes · a little further, still with bars and a check

Learn

These still use a letter for an unknown. Some have two steps. Invented classroom totals stay labeled invented.

Remember

A letter still stands for one number in a problem. Draw a bar, write an equation, then check.

Watch me

An invented box holds 35 blocks. 12 are red, n are blue, and the rest, 8, are yellow. Find n.

  1. The parts are 12, n, and 8, and the whole is 35 (invented).
  2. 12 + n + 8 = 35, so n + 20 = 35, and n = 15.
  3. Check: 12 + 15 + 8 = 35.

Together

On a balance we will study tomorrow, both sides will have to match. For today: n + 4 = 9 + 6. What is n?

Hint 1: The right side

9 + 6 = 15, so the equation is n + 4 = 15.

Hint 2: The unknown

n = 15 − 4 = 11. Check: 11 + 4 = 15.

Check

These go a step further, still with a check.

  1. A whole of n is made of 14 and 9 and 7. Find n.
  2. 3 + n = n + 3. What does this tell you about n, and what does it not tell you?

Practice

  1. n + n = 18. Find n.
  2. An invented shelf holds 40 books. 15 are on the first pile and n are on the second. The two piles together are the whole shelf. Find n.
  3. Why can we use the letter n again in this new shelf problem, even though n was 15 in an earlier problem?

Math circle: the same letter, the same number

20 minutes · a short argument, then a check of the reason

Learn

Why must the same letter mean the same number each time it appears in one problem?

Remember

In one problem, a letter is a name for one unknown number. If we let it change mid-problem, the picture and the check fall apart.

Watch me

A friend writes n + n = 10, then says “the first n is 2 and the second n is 8.” What would you say?

  1. n + n means two of the same number.
  2. 2 + 8 = 10 is a true sum, but it is not n + n unless n is both 2 and 8 at once, which a single letter cannot be in this problem.
  3. n + n = 10 means 2n = 10, so n = 5. Check: 5 + 5 = 10.

Together

Why is it still all right to use n tomorrow for a different unknown?

Hint 1: A new problem

A letter is a name we give for one sitting of a problem.

Hint 2: The habit

A new problem can reuse the name. Inside one problem, the name stays still.

Check

These check the reason.

  1. In n + 4 = 12, can n be 8 on the first line and 9 on the check? Why or why not?
  2. Give one reason we write a letter at all, instead of leaving a blank box forever.

Practice

  1. Write n + n + n = 15 as a short multiplication, and find n.
  2. A friend says a letter is “not a real number.” What would you say?
  3. This argument is not a score or a badge.

Spanish · la balanza, el peso, falta, and el lado

15 minutes · Instruction in English; Hear for Spanish words · present tense only

Learn

Word How to say it Meaning
la balanza lah bah-LAHN-sah the balance
el peso el PEH-soh the weight (the object on a pan)
falta FAHL-tah is missing
el lado el LAH-doh the side

Today’s words name a balance, a weight, “is missing,” and a side. Instruction stays in English. Equations and invented masses stay in the English mathematics.

Original sentences: Hay una balanza. Falta un peso. El lado es igual. Hay un peso.

For the guide: point to a drawn balance, then to one empty pan, as you say the words. This is present-tense description, not an equation lesson in Spanish. igual is already known from Day 31; lado appeared in a Week 5 story about triangle sides, and is named clearly today.

Remember

la balanza; el peso; falta; el lado. Instruction in English. Hear for Spanish words. No equations in the Spanish.

Watch me

Say: “There is a balance.”

  1. Hay una balanza.
  2. Hay introduces it. Una balanza is the balance.
  3. This is a present-tense pattern, not a past narrative.

Together

How do you say “A weight is missing”?

Hint 1: Is missing

falta

Hint 2: The sentence

Falta un peso.

Check

These use only today’s phrases.

  1. Write: “There is a weight.”
  2. Write: “The side is equal.”

Exercises

  1. Correct: *El balanza, if someone used the wrong article.
  2. Hear balanza, peso, and falta, then use each.
  3. Why does the Spanish not solve n + 5 = 12?
  4. A pointing retell: a balance, a weight, is missing, a side.
  5. Copy one model sentence into the notebook.

Latin · pondus and deest

15 minutes · Method: picture-based Latin; original sentences. Instruction in English.

Learn

Word How to say it Meaning
pondus PON-dus a weight (nominative, neuter)
Pondus magnum est PON-dus MAG-num est The weight is large
deest DEH-est is missing / is absent
Pondus deest PON-dus DEH-est A weight is missing

The Hear-word button uses an Italian voice as an approximation of Latin, not the speech of ancient Rome.

Original sentences, not from a textbook: Pondus magnum est. Pondus deest. Pondus nōn magnum est. Pondus nōn deest.

pondus is neuter, so magnum matches. Equations and invented masses stay in the English mathematics; no letters such as n, and no pan-balance arithmetic, in the Latin.

For the guide: the student reads as much as possible. Point to a drawn weight, then to an empty pan. Italian-voice Hear, labeled as an approximation.

Remember

pondus; Pondus magnum est; deest; Pondus deest. Instruction in English. Italian-voice Hear, labeled as an approximation. No equations in the Latin.

Watch me

Read: “The weight is large.”

  1. Pondus magnum est.
  2. pondus is the weight. magnum matches, because pondus is neuter.

Together

How do you say “A weight is missing”?

Hint 1: Is missing

deest

Hint 2: The sentence

Pondus deest.

Check

These use only today’s captions.

  1. Write: “The weight is not large.”
  2. Write: “A weight is not missing.”

Exercises

  1. Why is *Pondus magna est a miss?
  2. Hear pondus and deest, then use each.
  3. Why does the Latin not solve n + 6 = 15?
  4. A pointing retell: a large weight, a missing weight.
  5. Copy one model sentence into the notebook.

Notebook: a missing-part bar, and a because-sentence

about 1 hour · a bar with n, then because / but / so

Learn

Draw a bar with a missing part named n, then write a because / but / so sentence about what the letter does.

Remember

The bar shows the whole and the missing part. The stems explain the habit: a letter names one unknown, and we check it.

Watch me

For n + 6 = 15, draw the bar, then start: I write n for the missing part because ________.

  1. The because restates that n names the unknown part.
  2. A sound because: …it is the part I have not yet found…

Together

Finish: I write n for the missing part because ________, but n is not a new kind of number, so ________.

Hint 1: The but

…it is only a name for an ordinary number I can find…

Hint 2: The so

…I will find n and check it in the equation.

Check

The page should show the bar and complete stems.

  1. Draw the bar for n + 6 = 15, with 15 as the whole and 6 as the known part.
  2. Write a three-stem explanation (because / but / so) about what the letter n does.

Practice

  1. Tick the word-bank words you used: unknown, letter, bar, check, equation.
  2. Write the value of n, and a check, on the page.
  3. The page is a record, not a score.
  4. File the page. It is not a reward.
