Unit 3 · Day 14 · Different parts, one bar

Today's big question: How do you add or subtract fractions when the parts are not yet the same size — for example 1/2 and 1/6?

For the guide: a 6-part bar is the concrete step; do not jump to a least-common-multiple trick before the bar is seen. Keep mass and pull distinct if a gravity example is used. Answers go in the math notebook; check them with the key only after the work is done.

Mental math warm-up: finding a common size of part

10 minutes · say the answer, then explain how you got it

Learn

To compare or combine 1/2 and 1/6, you need parts of the same size. Sixths work, because 1/2 = 3/6 (Day 12). Once the parts are the same size, you are back in yesterday’s rule: 3/6 + 1/6 = 4/6. A number that both denominators divide is a common denominator. For 2 and 6, 6 works.

Remember

To add unlike fractions, first rename them so the denominators match (a common denominator), then add as like fractions. 1/2 = 3/6.

Watch me

Rename 1/2 as sixths, then add 1/6.

  1. 1/2 = 3/6 (multiply top and bottom by 3).
  2. 3/6 + 1/6 = 4/6.
  3. 4/6 = 2/3 (optional rename).

Together

What is 1/2 − 1/6?

Hint 1: Same parts

1/2 = 3/6.

Hint 2: Subtract

3/6 − 1/6 = 2/6, which is 1/3.

Check

Rename, then add or subtract.

  1. 1/3 + 1/6 = ?
  2. 2/3 − 1/6 = ?

Practice

  1. 1/2 + 1/4 (use fourths).
  2. 3/4 − 1/2.
  3. 1/3 + 1/3 + 1/6.
  4. A 6-part bar: mark 1/2 and 1/6 and say what is left of the whole.

Core lesson: unlike denominators, and 1/6 again

35–40 minutes · Method: a bar that can show both unit sizes, then the common-denominator rule

Learn

Fractions with unlike denominators have parts of different sizes. You cannot add the numerators until the parts match.

A 6-part bar can show halves and sixths, because 1/2 is 3 of the 6 parts.

1/2 + 1/6 = 3/6 + 1/6 = 4/6 = 2/3.
1/2 − 1/6 = 3/6 − 1/6 = 2/6 = 1/3.
1/3 + 1/6 = 2/6 + 1/6 = 3/6 = 1/2.

Gravity. Earth’s pull is 1, or 6/6 on the bar. The Moon’s pull is about 1/6. The difference is 1 − 1/6 = 5/6: Earth’s pull is 5/6 stronger than the Moon’s, in the sense that you add 5/6 of Earth’s pull to the Moon’s pull to recover Earth’s. The ratio remains about 1/6. Keep those two ideas separate.

The rule. Find a common denominator (often a multiple of both denominators). Rename each fraction. Then add or subtract as like fractions, and rename if you can.

Concrete step. On a 6-cube train, 3 cubes are 1/2, 1 cube is 1/6. Together, 4 cubes are 4/6 = 2/3 of the train.

Remember

Unlike denominators: rename to a common denominator, then add or subtract as like fractions. 1/2 + 1/6 = 4/6 = 2/3; 1/2 − 1/6 = 2/6 = 1/3; 1/3 + 1/6 = 1/2. A 6-part bar shows halves and sixths. Mass still does not change on the Moon.

Watch me

Find 1/2 + 1/6 using a 6-part bar, and write every renaming step.

  1. 1/2 = 3/6.
  2. 3/6 + 1/6 = 4/6.
  3. 4/6 = 2/3.

Together

Earth’s pull is 1. The Moon’s is about 1/6. What is 1 − 1/6, and what does that number mean (and not mean)?

Hint 1: The subtraction

1 = 6/6, so 6/6 − 1/6 = 5/6.

Hint 2: The meaning

5/6 is how much of Earth’s pull you would add to the Moon’s pull to make Earth’s. It is not a new gravity for a different world, and it is not a change of mass.

Check

These questions use a common denominator, then like-fraction arithmetic.

  1. 1/3 + 1/6 = ? Show the renaming.
  2. 2/3 − 1/2 = ? (A common denominator of 6 works: 4/6 − 3/6.)

Practice

  1. 1/2 + 1/6, 1/2 − 1/6, and 1/3 + 1/6, each in simplest form.
  2. 1/4 + 1/2 and 3/4 − 1/6 (for 1/6, a common denominator of 12: 9/12 − 2/12).
  3. A 6-part gravity bar: Earth’s pull 6/6, Moon 1/6. Write the difference, and write the ratio of Moon to Earth.
  4. A student writes 1/2 + 1/6 = 2/8. Correct the error and say what rule was skipped.
  5. Write a because-sentence: I changed 1/2 into 3/6 before I added 1/6 because ________.

Challenge problems: three unlike parts, and Mars again

20 minutes · common denominators, including a labeled estimate

Learn

Sometimes three fractions need a common denominator: 1/2 + 1/3 + 1/6. Sixths work: 3/6 + 2/6 + 1/6 = 6/6 = 1. Mars gravity, about 19/50 of Earth’s, can be compared with 2/5 only if you say 2/5 is a slightly high estimate (Day 12).

Remember

Find one common denominator for all the fractions, rename, then add or subtract. Label 2/5 as an estimate if you use it for Mars.

Watch me

Compute 1/2 + 1/3 + 1/6.

  1. Common denominator 6: 3/6 + 2/6 + 1/6.
  2. 3 + 2 + 1 = 6 sixths: 6/6 = 1.
  3. The three parts make one whole.

Together

Is 1/6 + 1/3 closer to 19/50 or to 2/5, or is that the wrong comparison? First find 1/6 + 1/3.

Hint 1: The sum

1/6 + 1/3 = 1/6 + 2/6 = 3/6 = 1/2.

Hint 2: Mars

1/2 is 25/50, which is larger than both 19/50 and 2/5 = 20/50. So 1/6 + 1/3 is not a Mars figure; it is half. The question is a check that you compute first, then compare honestly.

Check

Compute first, then compare if asked.

  1. 1/4 + 1/3 (denominator 12).
  2. 1 − 1/6 − 1/3 = ?

Practice

  1. 1/2 + 1/3 − 1/6.
  2. 5/6 − 1/2.
  3. Earth pull 50 units. Moon, about 1/6 of 50. Mars, 19/50 of 50. Write both, then say which world has the stronger pull.
  4. (Stretch.) 1/2 − 19/50. How much more than Mars’s ratio is 1/2? Leave the answer in fiftieths.

Math circle: the smallest common denominator, and a trap

20 minutes · a diagram, then a short argument

Learn

Any common multiple of the denominators will work, but the least common multiple keeps the parts larger and the numbers smaller. For 4 and 6, 24 works, and so does 12, which is smaller. 1/4 + 1/6 = 3/12 + 2/12 = 5/12. If you used 24, 6/24 + 4/24 = 10/24 = 5/12 after renaming — the same amount.

Remember

Any common denominator works; the least one is often easiest. The trap is adding numerators and denominators (1/4 + 1/6 = 2/10), which is not addition of amounts.

Watch me

Show that 1/4 + 1/6 is not 2/10, and find the true sum.

  1. 2/10 = 1/5, which you can mark on a bar; 1/4 + 1/6 is 5/12.
  2. 5/12 compared with 1/5 = 12/60 against 12/60? 5/12 = 25/60, 1/5 = 12/60, so 5/12 is larger, and they are not equal.
  3. Adding 1+1 and 4+6 invented a different amount.

Together

Why does 12 work as a common denominator for 4 and 6, and why does 8 not work?

Hint 1: 12

12 is a multiple of both 4 and 6 (3 × 4, 2 × 6).

Hint 2: 8

8 is a multiple of 4, but not of 6, so you cannot rename 1/6 as eighths without a fractional numerator.

Check

The skill is choosing a denominator that both can become, and avoiding the add-everything trap.

  1. 1/4 + 1/6 = ? Use twelfths.
  2. Is 8 a common denominator for 1/2 and 1/8? Is it a common denominator for 1/3 and 1/8?

Practice

  1. 1/8 + 1/4, two ways if you wish (eighths, or sixteenths then rename).
  2. A two-sentence argument: I must not add 1/4 + 1/6 as 2/10 because ________. The true sum is ________.
  3. Find a common denominator for 3 and 8, and compute 2/3 − 1/8.
  4. Draw a 12-part bar that shows both 1/4 and 1/6, then their sum.

Spanish · Quiero ver la luna, and puedo

15 minutes · Instruction in English; Hear for Spanish words

Learn

You have met tiene and quiere (Day 8). Today quiero (I want) and puedo (I can), with ver (to see): Quiero ver la luna. Puedo ver la luna llena. No puedo ver la luna nueva. Ver stays in the infinitive after quiero and puedo.

Word How to say it Meaning
quiero kee-EH-roh I want
puedo PWEH-doh I can
ver behr to see
Quiero ver la luna kee-EH-roh behr lah LOO-nah I want to see the Moon
No puedo ver no PWEH-doh behr I cannot see

Remember

Quiero + infinitive: Quiero ver la luna. Puedo + infinitive: Puedo ver la luna llena. No puedo ver la luna nueva.

Watch me

Say in Spanish: ‘I want to see the full Moon.’

  1. Quiero ver la luna llena.
  2. quiero + ver, not ‘quiero veo’.
  3. luna llena from Day 13.

Together

Say: ‘I cannot see the new Moon.’

Hint 1: Cannot

No puedo.

Hint 2: See

ver la luna nueva.

Check

Use quiero / puedo / no puedo + ver and a phase word if you need one.

  1. Write: I want to see the Moon.
  2. Write: I can see the first quarter. (el cuarto creciente)

Exercises

  1. Translate: I want to see the sky. I cannot see the stars. (las estrellas — new, taught here: las estrellas, ‘the stars’.)
  2. Correct: Quiero veo la luna.
  3. Write two original sentences, one with quiero ver and one with puedo ver or no puedo ver.

Latin · Puella lūnam spectat

15 minutes · Method: picture-based Latin; original sentences. Instruction in English.

Learn

You have seen spectat (Day 9) and lūnam as something looked at. Today make the pattern clear: Puella lūnam spectat. Puer stēllās spectat. The thing being looked at takes the accusative (lūnam, stēllās). The one who looks stays nominative (puella, puer). Puella lūnam clāram spectat — the adjective clāram matches lūnam.

Word How to say it Meaning
spectat SPEK-tat looks at / watches
lūnam LOO-nam the moon (object)
stēllās STEL-lahs the stars (object)
clāram KLAH-rahm bright (feminine object)
Puella lūnam spectat poo-EL-lah LOO-nam SPEK-tat The girl looks at the moon

The Hear-word button uses an Italian voice as an approximation of Latin, not the speech of ancient Rome.

Remember

Nominative does the looking (puella, puer). Accusative is looked at (lūnam, stēllās). Puella lūnam spectat. Puer stēllās spectat. An adjective on the object matches it: lūnam clāram.

Watch me

Say in Latin: ‘The girl looks at the moon.’

  1. Puella lūnam spectat.
  2. lūnam, not lūna, because it is the object.
  3. spectat, not spectant, with one girl.

Together

Say: ‘The boy looks at the bright moon.’

Hint 1: The boy

Puer (nominative).

Hint 2: The bright moon

lūnam clāram spectat.

Check

Use the nominative/accusative pattern taught today.

  1. Write: The girl looks at the stars.
  2. Correct: Puella lūna spectat.

Exercises

  1. Translate: The boy looks at the moon. The girl looks at the bright stars.
  2. Write two original sentences, one with lūnam and one with stēllās.
  3. Correct: Puer stēllae spectat.

Notebook: a common-denominator bar, with because / but / so

60 minutes · draw first, then label, then write · How the notebook works · Review sheet

Learn

Draw one 6-part bar that shows 1/2 and 1/6, then their sum 4/6 = 2/3 and (on a second sketch or the same bar) the difference 2/6 = 1/3. Write stems that explain why you renamed 1/2 as 3/6 before adding.

Remember

Unlike denominators need a common size of part first. 1/2 + 1/6 = 2/3; 1/2 − 1/6 = 1/3. Because / but / so should name the renaming, not skip it.

Watch me

Finish: I wrote 1/2 as 3/6 because ________.

  1. Because I needed parts the same size as sixths in order to add 1/6.
  2. A 6-part bar makes 1/2 into 3 parts.
  3. The because should mention a common size of part, not ‘it looks nicer’.

Together

Finish: 1/2 + 1/6 is 2/3, so ________, but ________.

Hint 1: So

so four sixths of the bar are filled, which is two thirds

Hint 2: But

but I must not write 2/8 by adding the tops and bottoms as they stand

Check

The notebook work is the 6-part bar, both the sum and the difference, and the stems.

  1. What two results should the bar be able to show?
  2. What error must the but-sentence rule out?

Practice

How the guide helps today: stay for the writing steps. Draw first, then label, then say each stem aloud before it is written. Do not invent sentences for the student.

1. Draw. One 6-part bar showing 1/2 = 3/6 and 1/6, then the sum 4/6 = 2/3. A second bar (or the same bar cleared) showing 1/2 − 1/6 = 2/6 = 1/3. Optional: the gravity reading 1 − 1/6 = 5/6, labeled as a difference of pulls, not as a change of mass.

2. Label, from the word bank.

Word bank: unlike · common denominator · 1/2 · 1/6 · 3/6 · 4/6 · 2/3 · 1/3 · rename · pull

3. Write.

  • 1/2 + 1/6 = ________, and 1/2 − 1/6 = ________.
  • I renamed 1/2 because ________.
  • I do not add 1/2 + 1/6 as 2/8, so I do not ________.
  • Earth’s pull minus the Moon’s pull is ________, but the Moon’s pull is still about ________ of Earth’s.
