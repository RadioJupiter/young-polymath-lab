Mental math warm-up: doubling a radius, and a first look at 3.14 × 10

10 minutes · say the answer, then explain how you got it

Learn

The core lesson will name π and the circumference formula. This warm-up practices two pieces you will need: diameter is twice the radius, and 3.14 × a ten is a place-value shift of 3.14. If the warm-up comes first, the guide should say that 3.14 is the approximation of π you will use today, labeled as an approximation.

Remember

d = 2r, and r = d/2. 3.14 × 10 = 31.4. 3.14 × 100 = 314. These are place-value shifts of 3.14, not a new kind of multiplying.

Watch me

A circle has radius 6 cm. What is its diameter?

  1. Diameter is twice the radius.
  2. 2 × 6 = 12.
  3. The diameter is 12 cm.

Together

What is 3.14 × 10, and what is 3.14 × 100?

Hint 1: Tens

3.14 × 10 = 31.4 (the digits shift one place).

Hint 2: Hundreds

3.14 × 100 = 314.

Check

These use only d = 2r and a 3.14 place-value shift.

  1. Radius 9 m: diameter.
  2. Diameter 14 cm: radius.
  3. 3.14 × 20 (as 3.14 × 10 × 2).

Practice

  1. 3.14 × 7, if you would rather wait for the core lesson, may be left; otherwise 3.14 × 7 = 21.98.
  2. Why must 3.14 be called an approximation once π is named?

Core lesson: radius, diameter, and the distance around a circle

35–40 minutes · Method: concrete (string around a circular lid, then compare to the diameter), pictorial (the marked circle), then C = πd with a labeled approximation of π

Learn

A circle is the set of points at one fixed distance from a center. That distance is the radius r. The diameter d is a segment through the center, from one side of the circle to the other, and d = 2r.

Circumference is the distance around the circle. If you measure several different circles (a lid, a wheel, a drawn circle) and divide each circumference by its diameter, the quotient is a little more than 3, and it is the same number, as near as honest measuring can tell. That number is π (pi). π is not a terminating decimal; it is not 3.14 exactly, and it is not exactly 22/7. In this level we compute with a labeled approximation: usually π ≈ 3.14, and sometimes π ≈ 22/7 when the diameter is a multiple of 7, because the sevens cancel cleanly. We write the approximation we used.

The formulas. C = πd and, because d = 2r, C = 2πr. For a circle of diameter 10 cm, using 3.14: C ≈ 3.14 × 10 = 31.4 cm. For a circle of diameter 14 cm, using 22/7: C ≈ (22/7) × 14 = 44 cm.

Sourced sizes, now with a circumference. Level 7 used NASA’s equatorial diameters and refused a circumference, because the circle had not been taught. Today we may compute one, if we name π and the rounding. Mars’s equatorial diameter, as this course used the NASA fact sheet, is about 6,792 km. Using π ≈ 3.14: C ≈ 3.14 × 6,792 = 21,326.88 km, which we will say as about 21,300 km, rounded to the nearest hundred, and we will label both the π and the rounding. Earth’s equatorial diameter is about 12,756 km. Using π ≈ 3.14: C ≈ 3.14 × 12,756 = 40,053.84 km, about 40,050 km (or about 40,000 km if we round to the nearest thousand). A closer value, using a more precise π with NASA’s equatorial radius 6,378.137 km, is about 40,075 km; that closer figure is still 2π times a NASA radius, not a new laboratory measurement of our own.

A crater is not a perfect circle. NASA pages for Tycho, on the Moon, give a diameter of about 85 km. If we model the rim as a circle of diameter 85 km, then with π ≈ 3.14, C ≈ 3.14 × 85 = 266.9 km, about 267 km. That is a model. A real rim is not a perfect circle, so we will not call 267 km “the measured walk around Tycho.”

Remember

d = 2r. C = πd = 2πr. π is not exactly 3.14 or 22/7; those are labeled approximations. NASA diameters may be given a circumference only with π and rounding named. A crater circumference is a circle model, not a surveyed walk.

Watch me

A circle has radius 5 cm. Find the diameter, then the circumference using π ≈ 3.14.

  1. d = 2 × 5 = 10 cm.
  2. C ≈ 3.14 × 10 = 31.4 cm.
  3. The 3.14 must stay labeled as an approximation of π.

Together

Using π ≈ 22/7, find the circumference of a circle of diameter 14 cm.

Hint 1: The formula

C = πd ≈ (22/7) × 14.

Hint 2: Cancel

14 ÷ 7 = 2, so 22 × 2 = 44 cm.

Check

These use only d = 2r, C = πd, and a labeled π.

  1. A circle has diameter 8 m (invented dish, labeled invented). Using π ≈ 3.14, find C.
  2. Using π ≈ 3.14 and Mars’s diameter about 6,792 km, what circumference does this course write, and what must be labeled?

Practice

  1. Radius 7 cm, using π ≈ 22/7: find d, then C.
  2. Earth, about 12,756 km across: using π ≈ 3.14, compute C, then give a nearest-thousand rounding, with both labels.
  3. Tycho is about 85 km across (NASA). If we model the rim as a circle and use π ≈ 3.14, what C do we get, and what must the sentence still say?
  4. Why did Level 7 refuse a circumference of Mars, and why may we compute one now?
  5. A classroom tube has diameter 4 cm (invented). Using π ≈ 3.14, find C.

Challenge problems: two approximations, and a tube that is not a planet

20–25 minutes · the same formula, with a comparison of 3.14 and 22/7

Learn

3.14 and 22/7 are both approximations of π. They are close, but they are not equal to each other, and neither is π. When you compute both, you should expect a small disagreement, and you should say so.

Remember

C = πd = 2πr. Label the approximation. A small disagreement between 3.14 and 22/7 is expected. Invented tubes stay labeled. NASA sizes stay sourced.

Watch me

A circle has diameter 14 cm. Compute C using 22/7, then using 3.14, and say what the difference means.

  1. Using 22/7: C ≈ 44 cm.
  2. Using 3.14: C ≈ 3.14 × 14 = 43.96 cm.
  3. The two answers differ by 0.04 cm because the two approximations of π differ, not because the circle has two circumferences.

Together

Using π ≈ 3.14, find the radius of a circle whose circumference is 31.4 cm.

Hint 1: The formula backwards

C = πd, so d ≈ C / 3.14.

Hint 2: The numbers

31.4 ÷ 3.14 = 10, so d = 10 cm and r = 5 cm.

Check

These stay with C = πd and labeled π.

  1. An invented telescope tube has diameter 7 cm. Using 22/7, find C, and label the tube invented.
  2. Why is “Mars’s equator is exactly 21,326.88 km around” too sharp for this course?

Practice

  1. Which is larger, 22/7 or 3.14, and how do you know from the 14 cm example?
  2. A circle has radius 10 m (invented). Using 3.14, find C.
  3. Write one sentence that could head a page: π labeled, rounding labeled, crater called a model if it is used.

Math circle: why C/d is the same for every circle

20 minutes · a short argument, not a new unit

Learn

Why should a lid and a planet, if both are circles, share the same C/d? The short reason is scaling. If you enlarge a circle so that every length is multiplied by the same factor k, the diameter becomes k d and the circumference becomes k C. The quotient (k C)/(k d) is still C/d. That common quotient is π. The argument assumes the two figures are the same shape (circles), honestly enlarged. It is not a laboratory proof that our 3.14 is exact.

Remember

If all lengths scale by k, C/d does not change. That stable quotient is π. 3.14 remains an approximation.

Watch me

A circle of diameter 2 cm has some circumference C. A second circle is an exact enlargement, diameter 6 cm. What is its circumference, in terms of C, and what is the same about C/d?

  1. The scale factor is 3, because 6 = 3 × 2.
  2. The new circumference is 3C.
  3. The new C/d is 3C / 6 = C / 2, which is the same as the first C/d.

Together

Why does this argument not let us write “π = 3.14 exactly”?

Hint 1: What the argument gives

It gives that C/d is the same for all circles, and that number is π.

Hint 2: What 3.14 is

3.14 is a rounded stand-in we chose for computing, not the exact value of that quotient.

Check

The point is the scaling reason, not a new formula.

  1. If someone measures one lid carelessly and gets C/d = 2.9, should they invent a new π for lids? Why not?
  2. Why was a circumference of Mars not a different π from a circumference of a 10 cm circle?

Practice

  1. Give one sentence you want to keep into the unit check, about labeling 3.14.

Word How to say it Meaning

centrum KEN-trum the center
In circulō est in KIR-koo-loh est It is in the circle (place where, ablative)

The Hear-word button uses an Italian voice as an approximation of Latin, not the speech of ancient Rome.

Original sentences: Circulus rotundus est. Centrum in circulō est. Circulus nōn longus est, sed rotundus est.

No meters, no π, and no 3.14 in the Latin.

For the guide: Italian-voice Hear, labeled as an approximation. in circulō is place-where, ablative, already known from earlier units.

circulus rotundus est; centrum in circulō est. No SI units and no π in the Latin.

Notebook: a circle, a string, and a because-sentence about π

60 minutes · draw first, then label, then write · How the notebook works · Review sheet

Learn

Draw a circle, mark r, d, and the distance around. Write C = πd and d = 2r. Then because / but / so: I can give Mars a circumference, because I now have C = πd and a NASA diameter, but 3.14 is not π itself, so I will write “about 21,300 km, using π ≈ 3.14, rounded to the nearest hundred.”

Word bank: radius, diameter, circumference, pi, approximation, rounded, NASA, model, crater.

Remember

Draw and label first. Complete stems. Label every approximation and every rounding. A crater C is a model. The page is not a badge.

Watch me

A model sentence: C ≈ 21,300 km because 3.14 × 6,792 is 21,326.88, but 3.14 is an approximation and the hundred is a rounding, so I will not write “exactly 21,326.88 km.”

  1. The multiplication is shown.
  2. The but names both labels.
  3. The so blocks fake exactness.

Together

Finish: Tycho can have a model circumference of about 267 km, because ________, but a real rim is not a perfect circle, so ________.

Hint 1: The model

…NASA pages give a diameter of about 85 km, and 3.14 × 85 ≈ 267.

Hint 2: The limit

…I will not call 267 km a surveyed walk around the rim.

Check

The page should show the drawing, the formulas, and complete stems.

  1. Draw the marked circle and write C = πd, with one worked example (the 10 cm circle or the 14 cm circle).
  2. Write a three-stem explanation of Mars’s circumference that names π, the NASA diameter, and the rounding.

Practice

  1. Add the Tycho model, with the “not a perfect circle” tag, or a clear reason for leaving it out.
  2. Tick the word-bank words you used.
  3. The page is not a score.
  4. A note that 22/7 is also an approximation, if you used it.
  5. File the page. It is not a reward.
