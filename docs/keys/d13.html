Challenge problems: several like parts, and a leftover

Check. 1. 4/6 = 2/3. 2. 10/12 = 5/6, which is less than 1.

  1. 9/12 = 3/4 of the model has passed; 3/12 = 1/4, so 3 model days are left.

  3. A short, accurate story and the sum 3/6 = 1/2.
  4. You are taking one sixth from one whole, so 6/6 − 1/6 = 5/6 is left. The ‘1’ in 1/6 is one part, not one whole.
