Math circle: the heavy meteorite

Split the 9 into three groups of 3. Weighing 1: group A against group B. If one side is heavier, the heavy piece is in that group; if they balance, it is in group C. Either way, you now have 3 pieces. Weighing 2: put one of the 3 against another. The heavier side holds it; if they balance, it is the third piece. It works because every weighing has three possible results, so it can split the candidates into three equal groups. With three weighings: 3 × 3 × 3 = 27 pieces.

Notebook: the model walk map

A good page explains that if sizes and distances were drawn at the same scale, the planets would be invisible dots on any page that showed their orbits. Books enlarge the planets so we can see them, which hides how empty space is.
