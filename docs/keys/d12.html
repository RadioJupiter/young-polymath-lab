  5. The whole: 18.

Core lesson: equivalent fractions, and gravity as 1/6

Check. 1. 1/12, 2/12, 3/18, or any correct set such as 2/12, 3/18, 4/24. 2. 2/6 = 1/3.

  1. Three bars of equal length, same amount shaded, correctly labeled.
  2. 2 and 4; 4 and 8.
  3. 1/6 of 24 = 4 units.
  4. 1/2, because 3/6 ÷ 3/3 = 1/2 (or a 6-part bar with 3 shaded is half).
  5. A sentence that keeps mass the same and makes the pull about 1/6, with a because.

Challenge problems: gravity on Mars, and a careful estimate

Check. 1. 380/1000 = 19/50 after dividing by 20. 2. 19 units.

  1. 2/5 is larger by 1/50.
  2. 1/6 and 1/5 are not equivalent: 5/30 against 6/30, so 1/5 is larger. ‘Both small’ is not a test.
  3. Moon: 5 units. Mars: 19/50 of 30 = 570/50 = 11 2/5 units (or about 11, if rounded and labeled).
  4. Yes: 19/50 = 38/100. 0.38 and 0.380 are the same value; trailing zeros after the decimal do not change it.

Math circle: proving two fractions are the same amount

Check. 1. Yes: 3/6 = 1/2 and 2/4 = 1/2, so they are equivalent to each other. 2. Multiplying by 0/0 is meaningless, and multiplying only the top or only the bottom by 0 would change the amount (or make a zero denominator, which is not a fraction). The rule needs the same non-zero number on both.

  1. A 6-part bar with 2 shaded is 1/3 of the bar; 2/6 ÷ 2/2 = 1/3.
  2. Adding 1 to each gives 3/6 = 1/2, which is not 2/5 (2/5 = 4/10, 1/2 = 5/10). Adding the same number to top and bottom does not keep the amount.
  3. A real because about the same amount or the same multiply/divide step, and a real if about unequal wholes or a wrong step.
  4. All four marks reach the same place, the middle of the bar.

Notebook: a gravity bar, and because / but / so

Check. 1. A 6-part gravity bar (and the 12-part equivalent bar). 2. They must not say the mass itself became 1/6 as many kilograms.

Practice. A 6-part bar with 1 part for the Moon, and a matching 12-part bar with 2 parts, same length. Labels from the word bank.
