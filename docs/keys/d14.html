Mental math warm-up: finding a common size of part

Check. 1. 1/3 = 2/6, plus 1/6 is 3/6 = 1/2. 2. 2/3 = 4/6, minus 1/6 is 3/6 = 1/2.

  1. 2/4 + 1/4 = 3/4.
  2. 3/4 − 2/4 = 1/4.
  3. 2/6 + 2/6 + 1/6 = 5/6.
  4. 1/2 + 1/6 = 4/6, so 2/6 = 1/3 of the bar is left.

Core lesson: unlike denominators, and 1/6 again

Check. 1. 1/3 = 2/6, plus 1/6 is 3/6 = 1/2. 2. 2/3 = 4/6, 1/2 = 3/6, so 4/6 − 3/6 = 1/6.

  1. 2/3; 1/3; 1/2.
  2. 1/4 + 2/4 = 3/4; 9/12 − 2/12 = 7/12.
  3. Difference 5/6 of Earth’s pull; ratio about 1/6.
  4. The parts were not made the same size. 1/2 + 1/6 = 3/6 + 1/6 = 4/6 = 2/3, not 2/8.
  5. Because sixths are a common size of part, and 1/2 is 3 of those parts.

Challenge problems: three unlike parts, and Mars again

Check. 1. 3/12 + 4/12 = 7/12. 2. 1 = 6/6, minus 1/6 minus 2/6 is 3/6 = 1/2.

  1. 3/6 + 2/6 − 1/6 = 4/6 = 2/3.
  2. 5/6 − 3/6 = 2/6 = 1/3.
  3. Moon: 50/6 = 8 1/3 units. Mars: 19 units. Mars has the stronger pull of the two (still less than Earth’s 50).
  4. 1/2 = 25/50, minus 19/50 is 6/50 = 3/25. So 1/2 is 6/50 greater than 19/50.

Math circle: the smallest common denominator, and a trap

Check. 1. 5/12. 2. Yes for 1/2 and 1/8 (1/2 = 4/8). No for 1/3 and 1/8, because 8 is not a multiple of 3.

  1. 1/4 = 2/8, plus 1/8 is 3/8. (Sixteenths: 2/16 + 4/16 = 6/16 = 3/8.)
  2. Because 2/10 is a different amount; the true sum is 5/12.
  3. 24 works: 16/24 − 3/24 = 13/24.
  4. A 12-part bar with 3 parts (1/4) and 2 parts (1/6) marked, together 5/12.
