Core lesson: a letter for an unknown

Check. 1. n + 5 = 18, so n = 13. Check: 13 + 5 = 18. 2. A letter stands for a number we can find and check. It is a name for the missing part, not a sticker.

  1. n = 8, because 24 − 16 = 8. Check: 8 + 16 = 24.
  2. n + n is 2n, and 2n + 4 = 16, so 2n = 12 and n = 6. Check: 6 + 6 + 4 = 16. Both n’s are 6.
  3. In one problem the same letter means the same number each time. You can use n again in a new problem, but not as two different numbers in the same one.
  4. The bar’s whole is n; a part of 3 is marked off; 8 is left. So n = 8 + 3 = 11. Check: 11 − 3 = 8.

Challenge problems: two letters, or a hidden whole

Check. 1. n = 14 + 9 + 7 = 30. 2. The two sides are already the same for any number n, because adding 3 on the left or on the right is the same change. It does not, by itself, tell us a single value of n.

  1. 2n = 18, so n = 9. Check: 9 + 9 = 18.
  2. 15 + n = 40, so n = 25. Invented shelf. Check: 15 + 25 = 40.
  3. A new problem can reuse the letter. The letter only has to keep one meaning inside one problem.

Math circle: the same letter, the same number

Check. 1. No. The check has to use the same n you found. 8 + 4 = 12, so n = 8 stays 8. 2. A letter lets us write the missing part in an equation and talk about it, then find its value and check.

  1. 3n = 15, so n = 5. Check: 5 + 5 + 5 = 15.
  2. The letter is a name for a number. Once we find it, we have an ordinary number, and we can check it.
  3. A note that the circle is a reason to talk through, not a reward.
